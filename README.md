# 📦 Controle de Estoque em Ruby

Projeto simples de controle de estoque via terminal (CLI) desenvolvido em Ruby.  
O sistema permite cadastrar, remover, listar e atualizar produtos, além de salvar e carregar dados em arquivo JSON.

---

## 🚀 Funcionalidades

- 📌 Cadastro de novos produtos
- ❌ Remoção de produtos por ID
- 📋 Listagem de todos os produtos
- ➕ Adição de quantidade em estoque
- 💾 Salvamento de produtos em arquivo JSON
- 📂 Carregamento de dados salvos anteriormente
- 🔁 Interface em loop via terminal (menu interativo)

---

## 🛠️ Tecnologias utilizadas

- Ruby 3.x
- Programação Orientada a Objetos (POO)
- Manipulação de arquivos JSON
- Terminal (CLI)

---

## 📁 Estrutura do projeto

estoque-ruby/
│
├── app.rb

├── estoque.rb

## ▶️ Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/ItsTheDuds/controle-estoque-ruby.git
```

### 2. Acesse a pasta

  cd controle-estoque-ruby

### 3. Execute o sistema

  ruby app.rb

🧭 Menu do sistema

= = = MENU = = =
1. Cadastrar novo produto
2. Remover produto pelo ID
3. Listar todos os produtos
4. Adicionar quantidade em estoque
5. Salvar todos os produtos
6. Carregar produtos salvos anteriormente
7. Sair

💡 Exemplo de uso
Cadastra produtos
Gerencia quantidade em estoque
Salva os dados em JSON
Carrega os dados ao reiniciar o sistema
